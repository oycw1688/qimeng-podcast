# 憩梦AI播客 · 制作发布规范

> 2026-10-31 整理，2026-11-01 起每天按此执行。内容每天不同，样式和流程不变。有改动以欧阳总最新指示为准。

## 一、节目与写法

- 节目名：**憩梦AI播客**。「憩」是休憩的憩，不能写成「气梦」。
- 公众号：只用 **「憩梦拾光」**，不用其他公众号。
- 署名：**铭心追梦**（铭记的铭）。用于作者栏和正文第一行「原创：铭心追梦」。
- 口号：每天五分钟，听懂AI圈大事。
- 期号：EP.01 = 2026年10月31日，以后每期自动加 1。

## 二、主播与声音

- **追梦**（女主播）：东北话（zh-CN-liaoning-XiaobeiNeural）。讲新闻，主吐槽。
- **铭心**（男主播）：普通话（zh-CN-YunxiNeural）。捧哏，拉回正题，做总结。
- 开场由铭心自我介绍：「我是铭心，铭记的铭，心意的心」。追梦接着说「我是追梦」。
- 旧名「小梦」「阿希」不能再出现。脚本校验和听写抽查都会拦。
- 语速 +13%。每句单独合成，响度统一到 -16 LUFS。

## 三、内容结构（约 5–6 分钟）

1. **开场**：问好，报日期和星期，两人自我介绍。
2. **头条**：讲得最细，带关键数字。
3. **次要新闻**：第二条、第三条……一般 3–4 条。
4. **快讯**：两三条短消息，由铭心来念。
5. **收尾**：一句话总结，提醒「据报道」，请大家订阅，「明天早上八点见」。

## 四、吐槽尺度与事实

- 风格是「放开吐槽」的幽默对谈，但只吐槽现象，不人身攻击，不加新事实。
- **不编造数字**。数字都要来自资料来源，并在对谈里念出来。
- 没有证实的内容标「**据报道**」。收尾要提醒：「据报道」的内容还没得到官方确认，以公司公告为准。
- 每期列出资料来源（媒体名和链接）。

## 五、背景音乐

- **全部原创合成**：用代码逐点生成，不用任何采样、loop 或别人的作品，没有版权风险。
- 风格：**120 BPM**，明快、有活力的轻电子 / 流行。
- 结构：
    - 片头音乐独奏约 8 秒，然后人声进来。
    - **说话时音乐自动压低**（sidechain），不抢人声。
    - 换章节时有短促的转场音效。
    - 片尾音乐抬起，再淡出。
- 成品整体 **-16 LUFS**，128k 立体声 MP3，约 6 分钟、6MB。

## 六、网页播放器（podcast.qidream.cn）

### 已定的四条

1. **摘要卡片**：
    - 紫色虚线框：2px dashed rgb(88,40,140)，底色 rgb(239,234,255)。
    - 不加左侧黄边，左右对称。
2. **大标题**：先把一行排满再换行，不能上一行没满就折到下一行。
3. **大标题跟着章节变**：
    - 播到哪条新闻，就显示那条的短标题。
    - 快讯章显示「快讯：……」。
    - 开场和收尾显示本期总标题。换标题时有淡入效果。
4. **章节功能**：
    - 显示当前章节和本章进度。
    - 可以从章节列表选章，也能上一章、下一章。
    - 有「只听本章」开关。
    - 锁屏和耳机上能显示章节，也能切换章节。

## 七、公众号图文格式

- **标题**：`憩梦AI播客 YYYYMMDD AI早报`，例如「憩梦AI播客 20261101 AI早报」。
- **作者**：铭心追梦。正文第一行是小字「原创：铭心追梦」。
- **正文顺序**：
    1. 原创行
    2. 头图（只有一张）
    3. 音频卡片
    4. 紫色虚线框简介
    5. 新闻正文（今日头条 + 第 02 条… + ⚡快讯 + 注和来源）
    6. 订阅栏
    7. 结尾一行
- **头图**：按星期配色，带日期和期数，不用紫色系。
- **头图右侧方块**（2026-11-01 起）：就是 1:1 分享小图同款——专辑封面版式 + 顶部日期胶囊「2026.11.02 · 周一」+ 当天配色。方块正好落在头图最右侧 383×383 区域里，裁 1:1 时干净完整。
- **1:1 分享小图**：`share_square_900.jpg`（900×900，同款设计），每天自动生成，建草稿前预传进素材库（图片），media_id 记在当天 `meta.json` 的 `share_square_media_id`。
- **正文配色**：新闻标题、胶囊、竖线、数字高亮、订阅栏都跟当天头图同一套颜色。
- **不随星期变的部分**：
    - 紫色音频卡片。
    - 紫色虚线框简介：2px dashed rgb(88,40,140)，底色 rgb(239,234,255)，圆角 12px，字色 rgb(88,40,140)。
    - 简介框左右和头图对齐，框里只放当天内容，不加节目名或日期前缀。
- **摘要**：用当天头条标题一句话，不加「第N期」、日期或固定口号。
- **排版**：不能有空段落，标题、摘要和正文里不能有「示例」「预览」这类占位字样。
- **阅读原文**：填当天那期网页 https://podcast.qidream.cn/ep/YYYYMMDD/ 。

## 八、每天发布流程（早上 8:00，新加坡/北京时间）

1. 写当天的对谈 JSON 脚本，校验通过。
2. 合成音频，用听写抽查发音和名字。
3. 生成网页，用手机尺寸自动验收，然后部署到 podcast.qidream.cn。
4. **音频要在公众号网页后台手动上传**。
    - 接口只收 2MB / 60 秒以内的语音，放不下整期节目。
    - 上传后在草稿里插入音频卡片。
5. 建草稿，阅读原文自动设为当天网页，然后跑草稿核对。
   - 接口建草稿时自动带封面裁剪：2.35:1 = 整张头图，1:1 = 头图右侧方块（若微信拒收裁剪参数，就去掉重建，后台手动调）。
6. **发表前清单**（2026-11-01 欧阳总定，每期在后台逐项点好、保存、刷新确认，汇报时逐项说明）：
    0. **⚠️ 第一条·硬性：音频同步上传+自带音频卡片**（2026-11-01 定，同日欧阳总确认措辞）：音频文件照常上传到素材库并同步插入文章，文章里显示公众号自带音频卡片；不插自制网页播放器（它只通过「阅读原文」链到 podcast.qidream.cn）；已发表文章缺播放器是重大失误；任何一期缺播放器或音频文件，一律不发表，停在草稿并立刻通知欧阳总，不得静默跳过。
        - 自动核对：`check_draft.py` 的「自带音频播放器硬闸」必须 PASS（正文有 `<mp-common-mpaudio>` 且 voice_encode_fileid 非空，当天 `daily_v3/work/YYYYMMDD/qimeng_ai_YYYYMMDD.mp3` 存在）。
        - 发表时 `api_publish.py` 会重新拉草稿再查一次，不过就以退出码 3 中止并打印「缺少公众号自带音频播放器，禁止发表」，没有任何绕过参数。可先用 `--publish-draft MEDIA_ID --dry-run` 只跑硬闸。
        - 在后台网页里手动发表时，也要先肉眼确认头图下面有音频卡片再点发表。
    1. **封面**：点封面 →「从正文选择」→ 选当天头图（正文最上面那张）。不要用紫色旧封面。
    2. **1:1 小图**：能单独换图，就换成素材库里当天那张正方形分享图；不能单独换，就把 1:1 裁剪框拖到头图右侧方块上。
    3. **原创**：勾选「文字原创」。
    4. **合集**：选「憩梦AI播客」。
    5. **创作来源**：勾选「内容由AI生成」。
    6. **广告**：选「智能插入」；点不了就照常发表，汇报时说明。
7. **发表条件**，下面四条都满足才发表：
    - **正文里有公众号自带音频播放器，且当天 MP3 文件存在**（缺任何一个：不发表、停在草稿、立刻通知欧阳总）。
    - 核对**全部通过**。
    - 「创作来源：内容由AI生成」**已勾选并保存**。
    - **预览已推送到 oycw1688**。
8. 任何一项有问题，**停在草稿**，并说明原因。发表后告诉欧阳总。

## 九、托管

- 网页托管在**腾讯云 EdgeOne Makers**，项目名 qimeng-podcast，网址是子域名 **podcast.qidream.cn**，国内可以访问。
- **www.qidream.cn 官网不动**，不改它的解析和设置。
- 不再用 GitHub Pages：国内很多人打不开。
- 不再用 CNB：它不能托管网页。

## 十、安全

- 公众号密钥、access_token、EdgeOne Token、腾讯云密钥**一律不打印、不外传**，只保存在本机。
- **以下事项先问欧阳总**：
    - 花钱。
    - 提交审核或备案。
    - 改域名或 DNS。
    - 群发。
- 不删除有用的文件。改旧文件前先备份。
- 建议：腾讯云账号级密钥以后换成只开 DNS 和 EdgeOne 权限的子账号密钥。

## 每日加发播客（2026-11-01 欧阳总定，同日实测可行）
- 文章群发（开群发通知）成功后，在后台「新的创作」→「播客」，从素材库选当天音频，用同一标题「憩梦AI播客 YYYYMMDD AI早报」，描述填当天简介，合集选「憩梦 AI 播客」，创作来源选「内容由AI生成」。
- 发表时群发通知保持关闭：不推送、不占群发次数，但内容会出现在主页；可能要管理员扫码验证。
- 实测（11/1）：文章和播客可以同一天先后发，两条互不覆盖，在发表记录里分开显示。
- 2026-11-01 更新：文章发没发成，播客都照发。播客没有图文正文，只有 140 字的描述区（能放文字、链接、表情、图片），里面放：当天简介（压缩后）、当天带日期的正方形小图、当天网页链接；再用编辑器的「自动生成时间轴」生成章节时间点。
